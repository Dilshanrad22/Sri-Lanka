# Activity Images

This directory contains images for the Activities Page.

## Required Images

Please upload the following images to this directory:

### 1. **gardening.jpg**
- Scene: Traditional Sri Lankan village garden
- Elements: Vegetables, fruits, herbs, organic farming
- Style: Bright, natural, earthy tones
- Recommended size: 1200x800px

### 2. **yoga.jpg**
- Scene: Yoga/meditation in a peaceful village setting
- Elements: Nature background, greenery, peaceful atmosphere
- Style: Calm, soft lighting (sunrise or sunset)
- Recommended size: 1200x800px

### 3. **village-tour.jpg**
- Scene: Authentic Sri Lankan village walkthrough
- Elements: Paddy fields, traditional houses, locals
- Style: Warm, welcoming, golden hour lighting
- Recommended size: 1200x800px

### 4. **kids-activities.jpg**
- Scene: Village children playing or learning
- Elements: Happy children, outdoor games, cultural exchange
- Style: Joyful, vibrant, energetic

### 5. **cinnamon.jpg**
- Scene: Cinnamon harvesting or processing
- Elements: Hands peeling cinnamon, rolled sticks, traditional methods

### 6. **tea-picking.jpg**
- Scene: Tea plantation and tea picking
- Elements: Lush green tea bushes, tea pickers, mountains
- Style: Iconic Ceylon tea culture, misty/fresh morning

### 7. **cooking.jpg**
- Scene: Traditional Sri Lankan cooking
- Elements: Clay pots, spices, firewood, family cooking

## Image Guidelines

- **Format**: JPG or PNG
- **Size**: Keep images under 500KB for web optimization
- **Quality**: High resolution but compressed for web
- **Aspect Ratio**: 3:2 (landscape) works best
- **Content**: Authentic, high-quality photos showing real village life

## After Uploading

Once you upload the images:
1. Ensure all filenames match exactly (case-sensitive)
2. The images will automatically appear on the activities page
3. The website will use fallback placeholders if images are missing
